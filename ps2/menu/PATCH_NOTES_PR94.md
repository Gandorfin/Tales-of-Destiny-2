# Tales of Destiny 2 — PS2 English Patch Update

This update addresses playtest feedback from tabs 10 and 11, with fixes to shop prompts, menu text, map labels and ending credits.

## Fixes

- Fixed the shop sell confirmation displaying garbage characters instead of the confirmation prompt.
- Corrected text storage that could cause Kyoueisou, Normal+, Pickaxe, Ferry to Cherik and a cooking message to appear blank, damaged or truncated after boot.
- Restored the return path from the Venus & Braves preview to the game.
- Removed stray formatting markers from the Shinkuu Kassaijin, Demon's Finger and Carrot descriptions.

## Translation and menus

- Corrected several dialogue lines and a children's speaker label.
- Updated battle dialogue to use Revitalize instead of Resurrection.
- Changed mine location labels from Exit to Entrance and corrected Lienea's spelling on an affected sign.
- Updated the final-dungeon world-map label to Atamoni Ovum.
- Clarified the item-use confirmation and waiting messages.
- Corrected Laevateinn's name and added the missing space after the Ochre equipment prefix.

## Ending credits

- Updated character names to Miktran and Rimul.
- Corrected both appearances of the studio name J.C.STAFF.
- Updated the final translation credit to “Green Gel Group / English Patch.”

## Patching tools

- Improved compatibility with resources patched by earlier releases, including compressed menu and battle modules.
- Added clearer reporting when a resource cannot be updated, helping identify files that would otherwise retain older text.
- Added regression checks for shop pointers, relocated map labels and executable text storage.

Source: [PR94 — playtest feedback, tabs 10–11](https://github.com/Gandorfin/Tales-of-Destiny-2/pull/94), merged as [aae1152](https://github.com/Gandorfin/Tales-of-Destiny-2/commit/aae1152ca1a3a9541cd54be62c9361897a0c04f7).
