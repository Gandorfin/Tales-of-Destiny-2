Open-source English fan translation of Tales of Destiny 2 for PlayStation 2 and PSP.

Download the latest patch English manual Report a problem GitHub repository

Status

PS2 (SLPS-25172) complete

Latest release: QS v1.3.0. The whole game is English: every story scene, all 608 timed skits (retranslated at full length in v1.3.0, with each line's text speed set to fit its voice), menus, battle text, world map, titles, Quiz Book, enemy artes, boss lines, the movies with dialogue and the ending staff roll.

Known limits: text drawn into pictures (cooking recipe names, a poster in the Katz Village) stays Japanese, the enchant level up message is shortened because the game cuts it at about 32 characters, and about 766 dialogue records show their fifth line alone on a second page.

PS3: the v1.3.0 download was built without the disc layout fix, so a PS3 shows it as a blue disc. Run python ps2\menu\fix_disc_layout.py fix "your patched.iso" from a copy of the repository on your patched ISO before burning. Coming with the next PS2 release: every skit line finishes before the next speaker starts, and 30 skit lines are shortened for that.

PSP (ULJS-00097) playable

Latest release: PSP patch v0.3.2, one download with the variable width font (v0.3.1 also came without the lowercase font hack). Story, all 608 timed skits at full length with per line text speed, almost all menus, items, artes, titles, descriptions, the Quiz Book, battle enemy names, the movies with dialogue and the PSP staff roll are English. New in v0.3.2: one English typeface (Fira Sans) for dialogue, skits and menus with every letter its own width, lowercase in the bold menu text ("Kyle", "Normal"), the world map in English in all five eras (location names, signposts, the box puzzle, Kyle's ending monologue), about 100 more menu strings (all shop names, scene titles), Frostheim in the PSP only menus and the enemy name banner at the start of a battle.

Where it runs: PPSSPP on PC, Android (a development build, v1.20.4 or newer) and Switch, and the PSP emulator of a PS3. A PS Vita with Adrenaline plays it with infrequent crashes. A real PSP does not run it yet (a PSP-3000 stops on a white screen after the logos, a PSP-2000 crashed often with v0.3.1); this is being investigated.

Still Japanese: menu messages the patch does not apply yet (the button legends of most menus, some shop and cooking confirmations and cooking results, the field exit prompt, the airship landing message, the title message), the element and status kanji, the save screen's title and Gald line, the Illustration Book texts, the system menu picture, some enemy Mystic Arte banners and about 50 enemy arte names and boss lines.

How to play

  1. Download the patch from the releases page. PS2 and PSP are separate patches (PSP tags start with PSP_).
  2. You need your own dump of the Japanese game: SLPS-25172 for PS2, ULJS-00097 for PSP. Apply the xdelta patch to your ISO with Delta Patcher (original ISO in, patch in, Apply).
  3. Play the PS2 version on PCSX2, a real PS2 or a PS3 (see the PS3 note above), the PSP version on PPSSPP or a PS Vita with Adrenaline. A real PSP does not run the PSP patch yet.

New to the game? Read the English manual (controls, menus, battle system, characters) or get it as a PDF.

How to help

  • Report what is wrong. Open an issue or post in the forum thread with: PS2 or PSP, the patch version shown on the title screen, emulator or hardware, a screenshot, and where it happens. Japanese text, cut-off lines, wrong names, freezes and typos all count.
  • Playtest. A full playthrough with screenshots and suggested fixes finds what scans cannot. The PSP version needs this most.
  • Improve the text. Corrections to the script are pull requests on the repository; the README explains the text rules.
  • Draw. Latin fonts for both versions (both font tools take a PNG sheet), and English versions of textures that still show Japanese.
  • Reverse engineering. Open PSP problems: menu strings whose address the game builds in code (the patch only redirects data pointers so far), which shortened arte names fit the grid again with the variable width font, a look at the Monster Book screen (its names are probably English now), and why a real PSP fails while emulators and the PS Vita run the game (wanted: a crash report with the crash address from a real PSP). Details in the README; formats and offsets in TECHNICAL.md.

Tools

  • Hex to Japanese: decode the game's text bytes
  • Japanese to Hex: encode text for the game
  • The archive tools, menu and text patchers, the one-command PSP build and the audit live in the repository; its README explains how to build both patches from source.
