Green Gel ToD2 Patch

Open-source English fan translation of Tales of Destiny 2 for PlayStation 2 and PSP.

Download the latest patch English manual GitHub repository

Status

PS2 (SLPS-25172) complete

Every story scene, all skits, menus, battle text, world map, titles, Quiz Book, enemy artes, boss lines, the videos with dialogue and the ending staff roll. Proofread line by line against the Japanese. Latest release: QS v1.2.7.

Still open: the Magical Pot prompt (the only Japanese players still report), the required Lens on the Refine screen, and the enchant level up message (cut off at about 32 characters, so it is shortened).

From the next release after v1.2.7 the skits are retranslated at full length: the build sets each skit line's text speed so it fits that line's voice (SkyBladeCloud found the speed value), so lines no longer have to be cut short.

PSP (ULJS-00097) v0.2.0 released

The full script and skits, all menus, items, artes, titles, descriptions and the Monster Book are English, and dialogue, names and menus render in mixed case. A few menu corners are still Japanese and are being worked on. Latest release: PSP patch v0.2.0. The v0.2.1 pre-release is the same build without the lowercase font hack (capitals only) for devices and real hardware where v0.2.0 has problems.

How to play

  1. Download the latest patch archive from the releases page (PS2 and PSP are separate patches).
  2. You need your own dump of the Japanese game — SLPS-25172 for PS2, ULJS-00097 for PSP. The release notes explain how to apply the xdelta patch to your ISO.
  3. Play the PS2 patch on PCSX2 or real hardware, or the PSP patch on PPSSPP or a real PSP.

New to the game? The original instruction manual is available in English: read the manual (controls, menus, battle system, characters), or get it as a PDF.

Found a mistake or a screen that is still Japanese? Open an issue with a screenshot.

What the patch contains

  • 459 scenario files and all skits, with the text box and skit timing limits of the game respected
  • Menus and UI: items, equipment, shops, refine, enchant, cooking, customize, status, tactics, save, name entry, grade shop, Monster Book, Battle Memos
  • Character titles, party arte names and cut-in banners, arte extension banners, mystic arte banners, enemy encounter names, enemy arte names and boss lines
  • World map labels, signposts, ferry and minigame text, the ending, the Quiz Book
  • Hard-subtitled in-game videos and an English ending staff roll
  • A redrawn Latin font (since v1.2.3, drawn by dreck)

Tools

  • Hex to Japanese: decode the game's text bytes
  • Japanese to Hex: encode text for the game
  • Everything else (archive tools, menu patchers, audit script) lives in the repository; the README explains how to build the patch from source

Contributing

Corrections to the script, testing on real hardware, and help with the PSP version are all welcome. Work on a branch and open a pull request; an automated check keeps crash-class mistakes out.

The PSP port still has a few engine-level problems open to anyone who knows PSP reverse engineering: lowercase for the bold menu text (names, tabs, arte grid, Battle Rank), a proper half-width fix for the arte grid, the Monster Book display names, and real hardware compatibility (the lowercase font hack does not work on every device; a new PSP font is in progress). The technical notes are in the repository README.
